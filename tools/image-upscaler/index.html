How to Upscale an Image

  1. Choose or drop one JPEG, PNG, or WebP image (up to 15 MB and 2 megapixels).
  2. Select Upscale Image 2x. On first use, the browser downloads the AI model before processing your image.
  3. Compare the original and enlarged preview, then download the upscaled result as a PNG.

Private, Browser-Based AI Upscaling

This tool uses the Swin2SR classical 2x super-resolution model through Transformers.js. Processing runs locally in a browser worker; your image is not uploaded to ToolNest. The model files are downloaded the first time you use the feature. Upscaling estimates image detail rather than recovering guaranteed original pixels, so results vary by photo. The model is based on work released under the Apache 2.0 license.
