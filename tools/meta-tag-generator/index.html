How to Use the Meta Tag Generator

  1. Enter your page title and description. Write a specific title and a clear, accurate summary of the page.
  2. Add optional page details. Provide the canonical URL, author, website name, and a publicly accessible social image URL where appropriate.
  3. Choose your tag options. Select an Open Graph type and decide whether to include Twitter Card and robots tags.
  4. Generate and add the code. Copy the output into the page's <head>, then verify the published page and social sharing appearance with the relevant platform tools.

What These SEO and Social Meta Tags Do

Page title and description

Describe the page with a useful title and summary. Search engines may use them when presenting results, but can choose different text.

Canonical URL

Identify the preferred URL for a page when similar or duplicate versions exist. Use the full, correct URL for that page.

Open Graph and Twitter Card

Supply page titles, descriptions, and image details that supported social platforms can use when displaying shared links.

Robots directive

The optional setting outputs an “index, follow” directive. Only add it when that instruction is appropriate for the page.

Meta tags support clear page information; they are not a substitute for helpful page content, crawlable links, or a sound technical SEO setup. The optional keywords tag is included for compatibility, but major search engines generally do not use it to determine rankings.
